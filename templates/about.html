ABOUT SYSTEM

Batch Reactor AI

Sistem monitoring dan pengendalian batch reactor berbasis Artificial Intelligence.

Tentang Sistem

Batch Reactor AI merupakan sistem yang digunakan untuk membantu melakukan monitoring kondisi batch reactor, mendeteksi kondisi anomali, serta memberikan rekomendasi pengendalian reactor.

Sistem menggunakan pendekatan Machine Learning untuk anomaly detection dan Reinforcement Learning untuk memberikan rekomendasi pengendalian.

Tujuan

  • Mendeteksi kondisi anomali pada batch reactor.
  • Membantu monitoring parameter proses reactor.
  • Memberikan rekomendasi pengendalian reactor.

Teknologi

  • Python
  • Flask
  • Machine Learning
  • Reinforcement Learning
  • Bootstrap 5

System Modules

Anomaly Detection

Modul Machine Learning untuk melakukan klasifikasi kondisi reactor menjadi Normal atau Anomaly.

Reactor Control

Modul Reinforcement Learning yang memberikan rekomendasi tindakan pengendalian coolant berdasarkan kondisi reactor.
